opendial

An open catalogue of real FM radio stations, city by city, with each internet stream checked on a schedule. It starts with Accra, Ghana. opendial does not relay, record or store audio.

  • Listen and test the streams in this browser
  • Accra, the hand-edited list (stations/gh/accra.json)
  • Published cities (public/index.json, written by the scheduled check)
  • Source and documentation on GitHub
