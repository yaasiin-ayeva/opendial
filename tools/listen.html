circle-radio: listen to the streams

Plays each stream of the catalogue in this browser, one at a time, the way the game will: a plain audio element, straight from the station's server. Nothing plays before you click. No audio is recorded or stored.

Reading the columns. Scheme: a page served over HTTPS (the game) cannot play an HTTP stream. Playback: "playing" means the audio element fired its playing event; still listen, a stream can play silence or an advert loop. CORS fetch: a separate fetch() in cors mode, stopped as soon as the headers arrive; "allowed" means the server sent an Access-Control-Allow-Origin that accepts this page's origin (needed only for the car-radio sound filter, not for plain playback). "refused" also covers a server that did not answer the fetch at all. A page cannot read the header's value itself, only whether the browser accepted it. "Test all" starts each stream without a new click; a browser that blocks this reports NotAllowedError: click Play on one stream first, or allow sound for this page.
