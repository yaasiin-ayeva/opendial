Reading the results

Scheme
A page served over HTTPS cannot play an HTTP stream: browsers block it.
Playback
"played" means the audio element fired its playing event. Still listen: a stream can play silence or an advert loop.
CORS
A separate fetch(), stopped as soon as the headers arrive. "allowed" means the server accepts this page's origin, which is needed only to route audio through Web Audio (filters, visualisers), not for plain playback. "refused" also covers a server that did not answer.
Test all
Starts each stream without a new click. A browser that blocks this reports NotAllowedError: press Play on one stream first, or allow sound for this page.
Published
The stations that passed the last scheduled check, as apps receive them. "Every station" is the hand-edited list, including stations whose stream is down or unknown.
